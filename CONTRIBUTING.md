## What we are looking for
Are you a developer? A graphic designer? Full of innovative ideas to help users improve their mode of consumption? Then join us! We are always looking for new contributors

## Responsibilities

Ensure cross-platform compatibility for every change that's accepted. Android, IOS.
Create issues for any changes and enhancements that you wish to make. Discuss things transparently and get community feedback and get approved by me.
Be welcoming to newcomers and encourage diverse new contributors from all backgrounds.

## From Zero to offical app feature
First create an issue in Cross Design when it's a design change or in Feature releases when it's a code change.
Then wait until our next meeting, where we will discuss your issue/change/feature. In this meeting I will also approve it.
Now you clone the repository and fork the project.
Now you can start codeing.
The next step is to create a Pull Request to the main branch.
